# 💰 Smart Budget Advisor

A beginner-friendly Python project that analyzes a user's budget and provides a spending recommendation based on the entered amount.

## 📌 About the Project

Smart Budget Advisor is a simple command-line application built with Python. It accepts a budget from the user, validates the amount, classifies the budget into a category, and provides basic financial guidance.

## ✨ Features

- Accepts user budget input
- Validates budget range (₹1,000–₹10,000)
- Categorizes budgets into Low, Moderate, and   High
- Provides spending recommendations
- Simple and beginner-friendly interface

## 🛠️ Technologies Used

- Python 3
- Conditional statements
- User input
- F-strings

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
